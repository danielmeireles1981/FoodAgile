# 🍽️ FoodAgile

Bem-vindo ao repositório **FoodAgile**!

> **Este projeto faz parte da avaliação do Curso Técnico de Desenvolvimento de Sistemas para o Ensino Médio do SENAI.**

---

## 💡 Descrição

O **FoodAgile** é um aplicativo desenvolvido em **React Native**, voltado para a área de sistemas alimentícios. Seu objetivo é simular e agilizar processos de gerenciamento de pedidos, cardápios, clientes ou operações de restaurantes e lanchonetes. O projeto explora conceitos de desenvolvimento ágil e práticas modernas de desenvolvimento mobile, sendo ideal para o aprendizado e aplicação dos conhecimentos adquiridos no curso técnico.

---

## 🚀 Funcionalidades

- Cadastro e gerenciamento de pedidos
- Controle de cardápio e estoque
- Registro de clientes e histórico de consumo
- Interface mobile intuitiva e responsiva
- Código modular, facilitando a manutenção e expansão
- Práticas de desenvolvimento ágil

## 🔧 Como executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/danielmeireles1981/FoodAgile.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd FoodAgile
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Execute o app no emulador ou dispositivo:
   ```bash
   npx react-native run-android
   # ou
   npx react-native run-ios
   ```
